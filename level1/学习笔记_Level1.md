# Level 1 学习笔记：MLP 原理 → 训练 → 推理

> 我的核心理解：机器学习 = 不手写规则，让机器从大量数据里自动调出几十万个参数；
> 神经网络 = 实现这件事的"流水线"，名字借自神经元，本质是矩阵乘法 + 激活函数；
> "学习" = 用数据把权重表调到能算对答案为止。

---

## 一、怎么理解"层"（治懵专用）

**层不是立体结构，是流水线上的工位。** 每个工位只有一套动作：
一列数字进 → 乘一张权重表 → 一列新数字出。

```
[784 个像素] → ×W1(784×256) → [256 个数] → ×W2(256×10) → [10 个得分]
   输入层                      隐藏层                    输出层
```

三种用法解码：
1. **层 = 一列数字**（加工结果）："隐藏层"就是第一张权重表乘出来的 256 个数
2. **层 = 一个工位**（加工动作）："Linear 层" = 权重表做乘法这个动作；"256 个神经元" = 这一站的表是 784×256，出 256 个数
3. **层数 = nn.Linear 的个数 - 1**（隐藏层个数）；2 个 Linear = 1 个隐藏层

- **前向传播** = 货物走一遍流水线（像素进 → 乘 W1 → ReLU → 乘 W2 → 得分出）
- **训练** = 站在旁边调权重表：看货对不对(loss) → 追责到每个数字(backward) → 拧一点(step)
- **推理** = 权重表焊死，纯走流水线出货

## 二、MLP 原理

- **神经网络 = 一串矩阵乘法 + 中间夹非线性**（线代的实际应用）
- 每层做的事：`y = Wx + b`；`nn.Linear(784, 256)` 的规格被两端"夹死"，不能随便改
- **ReLU**（负数归零）提供非线性——没有它，叠 100 层线性层也等价于一层
- **输出层**：10 个席位各打一个分（logits）；argmax 最高分 = 预测；softmax 交给 loss 内部做，**最后一层后面永远不加激活**
- **参数量** = 784×256+256 + 256×10+10 = **203,530**（Level 2 要和 CNN 对比）

## 三、数据流水线

- **MNIST**：官方预分好 6 万训练 + 1 万测试；每条样本 = (图片, 标签)，就是 X 和 y——特征从"人工设计"变成"原始像素"
- **Tensor**：PyTorch 唯一数字容器；图像按 `[N, C, H, W]`（批、通道、高、宽），第 0 维永远是批
- **ToTensor()** 必做（换容器 + 0~255 缩到 0~1）；Normalize 可选，但训练/测试必须用同一个 transform
- **DataLoader** = 发题员：切批、洗牌（训练 True / 测试 False）、搬运；洗的是顺序，保证的是每张图每轮恰好出现一次
- **Flatten 放在模型里**而非 transform——拉平是 MLP 的需求，CNN 不需要

## 四、模型定义三步骨架（所有网络通用）

```python
class MLP(nn.Module):
    def __init__(self):              # ① 声明零件（只跑一次，层必须写在这）
        super().__init__()           #    不能省
        ...
    def forward(self, x):            # ② 装配说明：点名零件、跟着形状走
        ...
# ③ m = MLP() 后用 m(X) 调用（自动走 forward）
```

直线结构用 `nn.Sequential`；要拐弯的结构（ResNet 跳跃连接）必须手写 forward。

## 五、训练

- **损失函数** CrossEntropyLoss：把"猜得多离谱"压成一个数字；优化器 Adam(lr=0.001)：执行改权重
- **分工**：`backward()` 只算账（梯度 = 每个权重的责任），`step()` 才动手改
- **训练循环模板（Level 1~4 不变）**：

```python
for epoch in range(EPOCHS):              # 外循环：题库过几遍（1 epoch ≈ 860 批）
    for X, y in trainloader:             # 内循环：每批 64 张，权重更新 1 次
        X, y = X.to(device), y.to(device)   # 数据每批搬 GPU
        optimizer.zero_grad()            # 梯度默认累加，必须清零
        scores = model(X)                # 前向
        loss = loss_fn(scores, y)        # 打分（y 由 for 循环头"发"出）
        loss.backward()                  # 反向传播：只算不改
        optimizer.step()                 # 更新 20 万权重
```

- **锚点数字**：初始 loss ≈ 2.3（瞎猜）；epoch 1 应到 0.3x；收敛 < 0.1；曲线先陡降后趋平 = 健康
- **设备规则**：问什么用什么（mps 配 `torch.backends.mps.is_available()`）；模型搬一次、数据每批搬

## 六、评估与推理

- **三摞数据防泄露**：训练（改权重）/ 验证（调参，从训练集切 5 千）/ 测试（封存到答辩只碰一次）
  泄露 = 期末考的信息混进了准备过程（拿测试集调参、归一化统计含测试集）
- **评估循环**：`model.eval()` + `torch.no_grad()` + 只前向；统计技巧 `(pred == y).sum().item()`
- **推理 infer.py**：`MLP()` 先造骨架 → `load_state_dict` 灌权重 → `eval()` → `m(单图.unsqueeze(0))` → argmax
  外部图片三道预处理：灰度 → 反色 → 缩 28×28（和训练数据"说同一种语言"）
- **train 教、test 考、infer 用**：test 和 infer 是同一招式（纯前向），test 在考场（有答案，出准确率），infer 在江湖（无答案，给真实判断）

## 八、我的踩坑记录（面试素材）

| 坑 | 现象 | 教训 |
|---|---|---|
| 优化器绑死旧模型 | 新建 `m=MLP()` 后 loss 恒 2.3 不降 | **模型与优化器同建同用**，重建模型必须重建 optimizer |
| 变量名撞车 | `'Tensor' object is not callable`（第 2 批才炸） | 工具(loss_fn)和产物(loss)绝不同名 |
| notebook 状态残留 | 曲线起点异常/坐标轴 1e-9 偏移 | 重启内核才是"重新开始"；正式结果用脚本跑 |
| cuda 检查代码照搬 | `cuda.is_available()` = False | Mac 无 NVIDIA 显卡，用 `torch.backends.mps.is_available()` |

## 九、一句话总链

**像素 → 784 维向量 → 矩阵乘法+ReLU → 10 个得分 → loss → 反向追责 → 优化器微调 → 循环 4300 次 → 97% 的认字模型 → 存权重 → infer 上岗**
